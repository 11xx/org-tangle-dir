#+TITLE: org-tangle-dir

Tangle Org Babel blocks into a directory set once per heading.

A literate config that tangles into several directories repeats a full path
in every =:tangle= header, and moving a subtree's output means editing each
block.  org-tangle-dir puts the directory on the heading as a =tangle-dir=
property.  Child headings inherit it, and =(tdir "file")= in a =:tangle=
header expands to a file inside it.

A =tangle-dir= value is a path, or a Lisp form for paths such as
=(expand-file-name "foo" (xdg-config-home))=.  Forms are checked before they
run: every function they call must be in =org-tangle-dir-whitelist-functions=,
and every argument must be a literal or another allowed call.  Anything else
signals an error without being evaluated.

* Install

Requires Emacs 27.1.

#+begin_src elisp
(package-vc-install "https://github.com/11xx/org-tangle-dir") ; Emacs 29+
(require 'org-tangle-dir)
#+end_src

With Elpaca, =(elpaca (org-tangle-dir :host github :repo "11xx/org-tangle-dir"))=;
with straight.el, =(straight-use-package '(org-tangle-dir :host github :repo "11xx/org-tangle-dir"))=.

* Use

#+begin_src org
,#+PROPERTY: header-args :mkdirp yes
,#+PROPERTY: tangle-dir ~/.config

,* myapp
:PROPERTIES:
:tangle-dir: ~/projects/myapp
:END:
,#+begin_src sh :tangle (tdir "setup.sh")
echo "running setup"
,#+end_src

,** Config
:PROPERTIES:
:tangle-dir: (tdir-base "config")
:END:
,#+begin_src yaml :tangle (tdir "app.yml")
name: myapp
,#+end_src

,* Shell
,#+begin_src sh :tangle (tdir "myapp.sh")
export MYAPP=1
,#+end_src
#+end_src

Tangling writes =~/projects/myapp/setup.sh=, =~/projects/myapp/config/app.yml=
and =~/.config/myapp.sh=.  A heading takes the nearest =tangle-dir= on itself
or an ancestor, then the file-level =#+PROPERTY=.  Inside a property, use
=tdir-base= (alias of =org-tangle-dir-base=) to build on the parent heading's
directory; =tdir= (alias of =org-tangle-dir=) belongs in =:tangle= headers.
